# آنی دکتر | Ani Doctor

سامانه فارسی و شمسی نوبت‌دهی و مدیریت مطب برای یک پزشک؛ Modular Monolith + MVC + Service Layer با Laravel 13، PHP 8.4 و MySQL 8.

این نسخه کد مراحل P1 تا P8 را یکپارچه دارد: OTP و نقش‌ها، خدمات/شیفت/تقویم inline، رزرو اتمیک، پرداخت/اعتبار/استرداد، میز منشی و حضور، فرم خصوصی/اعلان، تخفیف و گزارش PDF/Excel و ابزارهای سخت‌سازی/بکاپ. وضعیت commit، ادغام و آخرین آزمون‌ها از GitHub و گزارش‌های هر مرحله خوانده شود؛ وجود کد به معنی نصب روی هاست واقعی یا تأیید بانک/SMS واقعی نیست.

## شروع نصب

برای نصب آسان، artifact موفق شاخه main در GitHub Actions را دریافت کنید؛ ZIP داخلی دارای vendor است. ZIP سورس GitHub vendor ندارد. npm/Node/Composer روی هاست برای بسته آماده لازم نیستند؛ PHP/MySQL/extension و Cron لازم‌اند. هیچ installer وب یا کاربر/رمز/OTP پیش‌فرض وجود ندارد. ورود لوکال هم به تنظیم SMS.ir نیاز دارد.

## حدود پذیرش

CI با SQLite/MySQL، سناریوهای هم‌زمانی/بازیابی، audit، کنترل بسته و نصب همان ZIP در Apache HTTPS موقت اجرا می‌شود. ارسال رویداد و پرداخت اینترنتی پیش‌فرض خاموش‌اند. انتشار عمومی به تنظیم واقعی هاست، TLS، پیامک/بانک، بکاپ قابل بازیابی و بررسی مستقل امنیت/حریم خصوصی نیاز دارد؛ ادغام در main این موارد را انجام‌شده نمی‌کند.
