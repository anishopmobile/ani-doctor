# آنی دکتر | Ani Doctor

سامانه اختصاصی نوبت‌دهی آنلاین و مدیریت مطب برای **یک پزشک متخصص زنان، زایمان و نازایی**.

> وضعیت این شاخه: **P4 پرداخت و اعتبار** روی P1 تا P3؛ زرین‌پال با verify، قطعی‌سازی اتمیک، اعتبار ناشی از لغو/پرداخت تخصیص‌نیافته، استرداد دستی قابل پیگیری و حالت اضطراری مدت‌دار. درگاه پیش‌فرض غیرفعال است؛ فعال‌سازی نیازمند تنظیم امن و آزمون محیط هدف است. [راهنمای P4](docs/P4.md) · [شواهد واقعی](docs/P4-VALIDATION.md). ساخت بسته به معنی نصب هاست یا پرداخت واقعی موفق نیست.

> افزوده این شاخه: **P5 میز کار مطب**، داشبورد روزانه و شخصی، بیماران و سابقه نوبت، رزرو تلفنی/فوری، دریافت کامل حضوری و مدیریت حضور با تاریخچه و کنترل رقابت. [راهنمای P5](docs/P5.md) · [نتایج واقعی](docs/P5-VALIDATION.md). P1 تا P4 پیش‌نیاز این شاخه‌اند؛ PRها هنوز merge نشده‌اند.

> افزوده فعلی: **P6 فرم خصوصی و اعلان رویداد**؛ فرم‌ساز نسخه‌دار، پاسخ رمزگذاری‌شده و مجوز مستقل، outbox پیامک قطعی/تغییر/لغو/یادآوری/منشی با retry محدود. ارسال رویداد پیش‌فرض خاموش است. [راهنمای P6](docs/P6.md) · [شواهد واقعی](docs/P6-VALIDATION.md).

## فناوری پایه

PHP 8.4، Laravel 13، MySQL 8، Blade، Bootstrap 5، Tabler، Vanilla JavaScript/Fetch API، تقویم جلالی، SMS.ir و زرین‌پال.

معماری: **Modular Monolith + MVC + Service Layer**. نیازی به میکروسرویس، SPA یا build پیچیده Frontend نیست. فایل‌های CSS/JS آماده و نسخه‌بندی‌شده در `public/assets` قرار می‌گیرند.

## سیاست توسعه

هر قابلیت تنها پس از تعریف معیار پذیرش در PRD و تست، پیاده‌سازی شود. هیچ `.env` یا کلید واقعی نباید commit شود. ارسال تغییرات به GitHub باید همراه با مستندات مرتبط و آزمون باشد.

## GitHub Actions

Workflow با push و PR اجرا می‌شود: تست‌های SQLite و MySQL، هم‌زمانی OTP، rollback، قالب‌بندی و بررسی وابستگی‌ها؛ سپس بسته‌بندی ZIP دارای `vendor/`. بسته P1 فقط زیرساخت هویت است. موفقیت واقعی هر اجرا و وجود artifact از تب **Actions → Artifacts** بررسی شود؛ وجود workflow به معنی موفقیت آن یا نصب روی هاست نیست.
