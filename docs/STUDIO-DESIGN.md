# Contemporary clinic visual refresh

Scope: public home/services/articles/CMS layouts and the shared operational workspace. This follows the owner's visual review of the first Tabler design. Public pages use an editorial composition with warm brand accents, original clinic illustration, generous typography, service cards and a contrasting appointment banner. The workspace uses an ink sidebar, consistent line icons, contextual welcome, operational shortcuts and existing real daily counts. No invented testimonials, metrics, qualifications or appointment confirmations are added.

Local sources: public/assets/studio.css, public/assets/clinic-art.svg and resources/views/components/ui-icon.blade.php are original project assets. The illustration is decorative, not a photograph or representation of the actual physician. All fonts, Tabler, calendars and select dependencies remain bundled; no new library, CDN, runtime package or build is required. Existing CMS colors, logo, content publication and private media policies remain authoritative. Marketing and panel rules are scoped separately. Mobile layouts retain native fallback, visible focus and reduced-motion support.

No routes, authorization, database schema, booking rules, payment or SMS provider contracts change. Rollback consists of reverting the visual commit. tests/Browser/controls.mjs additionally checks public home/services/articles at 320/768/1440px, real admin desk shortcuts/overflow, and prohibits external resource requests. Its existing date/select, dynamic builder, role denial, CSRF-backed form and no-JavaScript checks continue. Screenshots are review evidence; automated viewport checks do not certify every browser or assistive technology.
