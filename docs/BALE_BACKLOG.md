# برنامه آینده بله

این فهرست از نیازسنجی تأییدشده «نیازسنجی اتصال بله» استخراج شده است؛ خارج از محدوده اصلی این شاخه، به‌جز حداقل اعلان و صندوق لازم برای گردش فعلی.

| شناسه | قابلیت |
|---|---|
| BF-01 | نوبت‌های من |
| BF-02 | لغو و تغییر نوبت |
| BF-03 | پیگیری وضعیت رسید |
| BF-04 | یادآوری مراجعه |
| BF-05 | صندوق پیام منشی |
| BF-06 | پاسخ‌های آماده |
| BF-07 | اعلان مدرک بررسی‌شده |
| BF-08 | مدیریت اتصال بله در پنل مدیر |

اعلان عمومی پاسخ آماده، حداقل ضروری گردش مدارک فعلی است؛ مدیریت کامل اعلان و اتصال‌ها همچنان backlog است. هیچ پرونده‌ای از تطبیق صرف شماره موبایل به حساب بله واگذار نمی‌شود.
