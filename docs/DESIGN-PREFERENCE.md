# سبک تأییدشده UI و UX آنی دکتر

به درخواست صریح مالک، سبک تأییدشده تا PR #16 و کامیت مرجع `8ccc9e8` مبنای طراحی صفحات و قابلیت‌های بعدی Ani-Doctor است. طراحی تازه باید ادامه همین سیستم باشد؛ تغییر مستقل سبک نیازمند درخواست یا تأیید مالک است.

- فارسی و RTL، فونت محلی Vazirmatn، Tabler محلی و توکن‌های رنگ مشترک موجود حفظ شوند.
- کارت‌های نرم، فاصله‌گذاری خوانا، چیدمان مناسب دسکتاپ و نمایش تک‌ستونی مناسب موبایل ادامه یابد.
- مسیر کار برای بیمار و منشی کم‌تجربه روشن باشد: مرحله‌های مشخص، اقدام بعدی واضح، متن ساده و گزینه‌های اختیاری قابل جمع‌شدن.
- فهرست‌های مدیریتی خلاصه، فرم‌های قابل بازکردن، جستجو با دامنه روشن، خطای متصل به همان فرم و حفظ ورودی ویرایش‌شده استفاده شوند.
- انتخاب بیمار، تاریخ شمسی، جستجوی select، پیش‌نمایش، ذخیره و انتشار مطابق قراردادهای فعلی باقی بمانند.
- دسترس‌پذیری صفحه‌کلید، focus، وضعیت بارگذاری/خطا و تأیید اقدام مخرب رعایت شوند.
- منابع و وابستگی‌ها داخل پروژه و با مجوز مناسب باشند؛ CDN یا قالب و سیستم طراحی موازی اضافه نشود.
- بهبود ظاهر و سهولت استفاده نباید مجوز، محرمانگی، ظرفیت، پرداخت یا قواعد کسب‌وکار را دور بزند.

## ثبت و تحویل تغییرات

طبق درخواست مالک، تکمیل کار موفق باید شامل ثبت و ارسال تغییرات مجاز به GitHub باشد؛ فایل محلی به‌تنهایی تحویل نهایی نیست. وقتی مالک انتقال تغییرات تأییدشده به `main` را می‌خواهد، ادغام و نتیجه واقعی CI گزارش شوند. تغییرات تازه‌ای که هنوز تأیید نشده‌اند روی شاخه جدا باقی بمانند. قواعد PR، تست و امنیت مخزن همچنان برقرارند.

این یادداشت ترجیح طراحی و روش تحویل را ثبت می‌کند و تغییری در کد اجرایی یا داده‌های برنامه نمی‌دهد.
